# Chario Shop — Site officiel

Site vitrine professionnel pour **Chario Shop**, boutique de produits numériques.

## Structure

```
chario-shop/
├── index.html              → Accueil
├── boutique.html           → Page Boutique / Produits
├── a-propos.html           → À propos (mission & vision)
├── conditions.html         → Conditions d'utilisation
├── confidentialite.html    → Politique de confidentialité
├── contact.html            → Contact
├── css/style.css
├── js/main.js
└── assets/logo.jpg         → Logo officiel
```

## Avant de publier

1. ✅ Le lien de la boutique Chariow a été configuré : `https://ldvfiryt.mychariow.shop`
2. (Optionnel) Connectez le formulaire de contact à Formspree, Netlify Forms ou un service similaire.

## Déploiement rapide

- **Netlify** : glissez-déposez le dossier → URL gratuite instantanée
- **Vercel** : importez le dossier
- **GitHub Pages** : poussez le dossier dans un dépôt

Le site est entièrement responsive, optimisé mobile, et prêt pour la production..
